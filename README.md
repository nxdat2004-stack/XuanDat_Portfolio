# Nong Xuan Dat — Meta Ads Portfolio

Single-page case study site. Ready for GitHub Pages.

## Upload to GitHub

1. github.com → **New repository** → name it (e.g. `meta-ads-portfolio`) → **Public** → Create
2. Inside the repo: **Add file → Upload files** → drag in **all files from this folder** (`index.html`, `12-concept-lines-hapas.html`, `image-slot.js`, and every `.jpg`) → Commit
3. **Settings → Pages** → Branch: `main` / `(root)` → Save
4. Your site goes live at `https://YOUR-USERNAME.github.io/REPO-NAME/`

Keep every file in the repo root — the page loads images and the embedded concept panel by filename from there.
